Đẩy kết quả lên GitHub

Lưu 11 kết quả vào một file — ví dụ docs/01-project/homework-04.md — rồi đẩy cả thư mục dự án lên GitHub.

  1. Tạo tài khoản ở github.com (nếu chưa có).
  2. Cài Git từ git-scm.com — kiểm bằng git --version.
  3. Trên GitHub bấm New → tạo repository, để Private.
  4. Copy đường dẫn repo, rồi chạy sáu lệnh dưới đây.
git init
git add .
git commit -m "Bài tập buổi 04"
git remote add origin <đường-dẫn-repo>
git branch -M main
git push -u origin main
Không bao giờ đẩy mật khẩu hay khoá bí mật lên GitHub. Nếu dự án có file .env, thêm nó vào .gitignore trước khi commit.
