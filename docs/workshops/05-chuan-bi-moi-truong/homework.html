    Việc mới — viết autotest cho luồng đăng nhập

    Bảo Jarvis viết một ca kiểm thử đi trọn luồng, rồi chạy lại bộ test để thấy số ca tăng thêm một.

    Prompt gợi ý
    Dùng skill @ai-skills/jarvis/README.md, viết autotest cho luồng: Mở trang login → đăng nhập với username admin@gmail.com và password Admin@123 → vào được trang dashboard. Xong thì chạy lại toàn bộ test và cho tôi xem kết quả.
    Chụp kết quả test hai lần: một lần trước khi thêm ca này, một lần sau. So hai con số — đó là thói quen sẽ thành luật cứng ở buổi 10.

Sáu thứ phải nộp

tích khi xong

  • Mở npm run dev rồi chụp màn hình đăng nhập.

  • Chạy backend rồi mở trang tài liệu API.

  • Chụp trước khi thêm autotest luồng login.

  • Mở trang login → đăng nhập admin@gmail.com / Admin@123 → vào được trang dashboard.

  • So với ảnh ở mục 3 — số ca phải nhiều hơn.

  • Cùng một repo với tài liệu — code và tri thức dự án nằm chung một chỗ.
